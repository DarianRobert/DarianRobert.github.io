An end-to-end pipeline for classifying complex temporal human movements from raw video. Combines CNN-based spatial feature extraction with LSTM sequence modelling so the system learns from how a motion unfolds over time, not just what a single frame looks like. The core challenge was structuring high-dimensional sequential data so the temporal signal did not get washed out, then tuning a deep network that was actually optimising for the right thing.

A scale and rotation-invariant computer vision pipeline classifying South African banknotes against cluttered, highly textured backgrounds. Built a custom sequential optimisation framework that benchmarked candidate algorithms through a data-isolated ablation study across three phases: preprocessing (CLAHE, bilateral filtering, Gaussian blur), segmentation (boundary isolation and geometric normalisation with strict protection against colour-data leakage), and classification (SIFT with FLANN, ORB, AKAZE, and 3D HSV histograms compared head-to-head).

  • Python
  • OpenCV
  • NumPy
  • Scikit-Learn
  • SIFT / ORB / AKAZE

A formal, machine-readable knowledge model establishing a shared semantic vocabulary for human analysts and automated reasoning engines. Formalises logical and mathematical relationships between cloud assets, vulnerabilities, threat actors, security controls, and compliance frameworks across IaaS, PaaS, and SaaS environments. Features over 60 logically defined classes, automated reasoning via HermiT to dynamically classify individuals, and threat and compliance mapping grounded in NIST SP 800-series, CSA CCM, and MITRE ATT&CK for Cloud. All structural relationships are translated into First-Order Logic and Description Logic for mathematical soundness.

  • OWL / RDF-XML
  • Protege 5.6.9
  • HermiT 1.4.3
  • SPARQL
  • OntoGraf

Solves the university lab allocation problem: assigning modules with varying enrolment sizes and software requirements to a limited pool of computer labs, minimising total unused seats. Uses a two-stage optimisation approach where a Greedy Algorithm generates a fast, feasible baseline solution respecting capacity and software compatibility constraints, then Hill Climbing Local Search iteratively improves it. Loads real lab and module data from text files, validates all constraints, and measures execution time for both stages. Built entirely on Python's standard library.

  • Greedy Algorithm
