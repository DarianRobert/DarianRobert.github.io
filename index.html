About

Engineering rigor
across every layer.

I'm a software engineer drawn to problems with more than one layer. A vision pipeline that has to survive bad lighting and a cluttered background. A model that reasons about motion over time rather than a single frame. A game loop that stays responsive at sixty frames per second.

My instinct is to break a system into phases, measure each one, and not trust a result I can't explain. That shows up across everything I build — from deep learning pipelines to C++ game engines built from a blank window up.

Selected Work

An end-to-end pipeline for classifying complex temporal human movements from raw video. Combines CNN-based spatial feature extraction with LSTM sequence modelling — the system learns from how a motion unfolds over time, not just what a single frame looks like. The core challenge was structuring high-dimensional sequential data so the temporal signal didn't get washed out, then tuning a deep network that was actually optimizing for the right thing.

A scale- and rotation-invariant computer vision pipeline classifying South African banknotes against cluttered, highly textured backgrounds. Built a custom sequential optimization framework that benchmarked candidate algorithms through a data-isolated ablation study across three phases: preprocessing (CLAHE, bilateral filtering, Gaussian blur), segmentation (boundary isolation and geometric normalization with strict protection against color-data leakage), and classification (SIFT with FLANN, ORB, AKAZE, and 3D HSV histograms compared head-to-head).

  • Python
  • OpenCV
  • NumPy
  • Scikit-Learn
  • SIFT / ORB / AKAZE
